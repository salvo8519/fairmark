IRR and XIRR now refuse a starting guess of −100% or lower (for XIRR, per compounding period) with a clear message naming `guess`; before, such a guess was silently ignored. This is a new version of each method (IRR version 3, XIRR version 2). Results for any other guess are the same, so only inputs with such a guess need changing: remove the guess or give one near the expected rate.
