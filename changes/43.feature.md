The DCF now accepts every terminal value technique on the enterprise basis, not only stable growth: the H-model, the value driver with return on new capital, an exit multiple of EBITDA, EBIT or sales, a finite horizon with a residual value, and a liquidation. The terminal value is the same as the technique computed on its own, its method version is reported, an equity multiple (P/E or P/BV) in an enterprise DCF is refused, and a sale price or liquidation value discounted half a year early under mid-year timing is flagged.
