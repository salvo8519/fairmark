The time value methods (day counts, rate conversion, real and nominal rates, NPV, present value, XNPV, IRR, XIRR, MIRR, annuities and perpetuities) are now available instead of preview: they passed an independent numerical audit and a code review. Their results do not change. Error messages now name the input to correct and say how, the calculation trail of MIRR shows every flow, IRR and XIRR show where the rate was found, and 30/360 year fractions show which day 31 was adjusted. The annuity page explains that very long annuities (for example more than 1,208 periods at 5%) return an error because their future value exceeds the number range.
