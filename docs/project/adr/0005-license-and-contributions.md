# ADR 0005 — Apache-2.0 and DCO

Status: accepted · 2026-11-07

## Decision
License the code under Apache-2.0 (explicit patent grant, widely accepted by enterprises and
financial institutions). Contributions are accepted under the Developer Certificate of Origin
(`git commit -s`). The project name and logo are not licensed under Apache-2.0.

## Consequences
+ Low friction for contributors and corporate adopters.
− Relicensing in the future would require consent from contributors (no CLA).
