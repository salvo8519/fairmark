# Brand

## Logo
The mark is an **F struck like a hallmark punch** on a navy seal; the gold diamond is the stamp
that certifies the value. Files live in `docs/assets/brand/`:

| File | Use |
| --- | --- |
| `mark.svg` | Primary mark, on light backgrounds; favicon |
| `mark-inverted.svg` | Mark on dark or navy backgrounds |
| `logo-light.svg` / `logo-dark.svg` | Horizontal lockup (mark + wordmark) |
| `banner-light.svg` / `banner-dark.svg` | README and announcements |
| `social-preview.png` | GitHub social preview (1280×640) |

Keep clear space around the mark of at least a quarter of its width. Do not recolour,
stretch, rotate or add effects. Text in the SVGs is outlined: no font needed.

## Palette

| Name | Hex | Role |
| --- | --- | --- |
| Ink Navy | `#0B1F3A` | Primary: logo, headings, dark surfaces |
| Deep Navy | `#12325C` | Links, interactive states |
| Hallmark Gold | `#C8A24A` | Accent, on navy only: the stamp |
| Ledger Green | `#0F7B5F` | Positive values, success |
| Signal Red | `#B42318` | Negative values, errors |
| Slate | `#475569` | Secondary text |
| Paper | `#F7F8FA` | Page background |

Gold is decorative: never use it for text on white (insufficient contrast).

## Typography
- **Inter** (600 headings, 400 body) — interface and documents.
- **JetBrains Mono** (500) — numbers, code, identifiers.

Both are open-source (SIL Open Font License).
