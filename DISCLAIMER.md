## Intended purpose

Fairmark is open-source software that computes valuation methods with deterministic,
rule-based calculations, specified in public documents and verified against test cases from
independent sources. It is published to improve the
accuracy of AI agents and analysts in financial analysis, by replacing figures estimated by a
language model with exact, reproducible and documented calculations.

Fairmark is a calculation tool. It is not an advisor: it does not decide and it does not
recommend.

## AI agents

When an AI agent calls Fairmark, the agent, and whoever operates it, chooses the method and
the inputs. An agent can choose the wrong method, extract wrong figures or misreport a result.
Fairmark computes only what it receives. Every result states the method, its version and the
conventions it used, every calculation step with the values substituted, and a fingerprint
(hash) of the inputs, so that a person can check it.
