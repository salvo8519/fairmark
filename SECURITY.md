# Security policy

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository. Do not open public issues for security reports.

A numerically wrong result is treated as a high-severity bug: open a *Numerical discrepancy*
issue (public) unless it can be exploited, in which case report it privately.
